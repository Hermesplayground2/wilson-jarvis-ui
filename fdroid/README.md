# Wilson Jarvis — F-Droid Distribution

## Add repo
In F-Droid or Droid-ify:
1. Settings → Repositories → Add repo
2. URL: `https://hermesplayground2.github.io/wilson-jarvis-ui/fdroid/repo`
3. Enable the repo

## Web app
Live URL: `https://hermesplayground2.github.io/wilson-jarvis-ui/`
Install on mobile home screen for app-like access.

## Build APK later
Use `fetch_prices.py` + this repo to generate a signed APK and update `index.xml` with real package metadata.
